Privacy by design

CSV, categorie e analisi restano sul dispositivo; nessun server obbligatorio. Esporta di tanto in tanto un file JSON e salvalo in File o iCloud: così non perdi nulla se cancelli i dati di Safari.

Periodo dalle date CSV

Le analisi si basano sulla data di completamento; il periodo suggerito segue gli estremi presenti nell’export. Puoi importare più file nel tempo: le righe si uniscono a quelle già salvate nel browser.

Azione irreversibile

Cancellare tutti i dati locali?

I file CSV non sono archiviati: restano solo nel browser ciò che è stato estratto e analizzato. Se procedi dovrai ricaricare gli export dalla scheda Coach.

  • Transazioni e saldi salvati sul dispositivo
  • Periodo e filtri delle analisi
  • Categorie riclassificate manualmente

Ripristinare questo backup?

Verranno sostituiti in questo browser transazioni, categorie personalizzate e impostazioni (incluso il periodo delle analisi) con il contenuto del file. L’azione non è annullabile dal pulsante «Annulla» dopo aver confermato.
